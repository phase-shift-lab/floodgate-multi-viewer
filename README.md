# Floodgate Multi Viewer

Floodgateの公開棋譜を1・2・3・4局で観戦するWebアプリです。フロントエンドはGitHub Pages、公開データのLIVE中継と匿名統計はCloudflare Workerで提供し、Worker未接続時は同梱fixtureへ安全にフォールバックします。

> 非公式ビューアです。Floodgateおよび運営組織による公式製品ではありません。

公開版: https://phase-shift-lab.github.io/floodgate-multi-viewer/

## 開発

Node.js 24系を推奨します。

```powershell
npm ci
npm run dev
```

検証:

```powershell
npm run lint
npm run typecheck
npm run test
npm run test:e2e
npm run build
```

## 構成

- `src/domain/`: CSA・HTML・レート解析、選定、再生ロジック
- `src/data/`: 同梱fixture、localStorage、LIVE中継クライアント
- `src/components/`: 盤面と対局パネル
- `worker/`: Floodgate公開データの許可リスト中継と匿名統計
- `e2e/`: デスクトップ、モバイル、再生、復元の検証

`VITE_API_BASE` にWorker URLを設定するとLIVE中継を利用します。未設定またはWorker障害時は「静的fixtureで表示中」へ切り替わります。ブラウザからFloodgate本体へは直接アクセスしません。

対局一覧より棋譜の終了情報が先に届いた場合も終了状態を反映します。終了時刻が明示された0手の棋譜は「不成立（0手終了）」と表示し、自動選出から除外します。確認済みの終了情報は端末に最大256件・24時間保持し、開き直した直後の選出にも反映します。配信元の手数が確認済みの値より増えた場合は、その終了情報を解除します。

起動時は着手のある対局を優先し、0手の自動選出候補は最大4局、各3秒で棋譜を確認してから採用します。確認済みの初手待ちはLIVEのままです。通信失敗・stale・fixtureの応答では終了情報を保存せず、未確認の0手対局は自動選出しません。保存が拒否されても起動時確認は継続し、候補がない場合は案内を表示します。共有URLで指定した対局はこの自動選出の除外対象にしません。

自動切替ONでは、終了確認時に次の30秒更新を待たず終了した枠だけを差し替えます。共有URLの指定・ピン留め・過去手の閲覧・詳細表示中の枠、自動切替OFFは維持します。通信失敗時は直前の盤面を保持し、60秒、以後最大120秒の間隔で再取得します。復帰後は通常の30秒間隔に戻り、非表示タブでは120秒間隔に抑えます。

## 端末での局面解析

つようら王11microと対応やねうら王WASMで現在の局面を端末上で解析します。初期ONで、盤面の上に先手基準の評価値・形勢ゲージ・第一候補・探索深さを表示します。ゲージは勝率ではありません。読み筋を押すと最大3候補と各6手までの日本語読み筋、解析ON/OFFを確認できます。対局ごとのOFF設定は保存し、OFF時はエンジンを読み込みません。CSAに含まれる評価値とは区別します。

エンジンは全盤で1つ、探索スレッド1、ハッシュ16MB、1局面500msです。複数盤は順番に解析し、局面変更時は古い探索を中止します。非表示時は探索を停止し、解析結果を最大128局面までメモリ内に保持します。観戦中に履歴全体を自動解析することはありません。端末のCPU・電池を使用し、実行メモリは評価ファイルの約4.9MBより大きくなります（WASM初期メモリ132MiB）。

共有メモリを利用するため、初回解析時にアプリのパス内限定のService Workerを登録し、1回再読み込みします。表示対局・手数・反転・解析ON状態をsessionStorageで一時復元します。Workerはキャッシュせず、同一アプリの応答にCOOP/COEPを付与します。外部通信にはヘッダーを追加しません。読み筋から開く詳細内の解除ボタンで登録を解除して再読み込みできます。解除後は自動解析を停止し、手動でONにすると再開します。再読込後も共有メモリを利用できない場合はエラー表示で停止し、再読込を繰り返しません。

解析局面・結果の送信、有料API、サーバー側の解析はありません。配布ライセンス・対応ソース・ビルド手順は `public/engine/NOTICE.txt` と `public/engine/source.zip` を参照してください。評価関数はMIT、探索エンジンはGPLv3です。

解析準備は局面更新と独立して継続し、初回の再読み込み直前に表示していた対局・手数、検討の手順を保存します。手動OFF・画面離脱では準備を中断します。中断と起動失敗を区別して表示し、失敗時は評価欄の「解析を再試行」から手動で再開できます。初回ON・手動OFFの保存と再読み込みループ防止は維持します。

## 共通の観戦・棋譜・検討画面

観戦・検討・棋譜を同じ画面に統合しています。未保存時のPCの初期表示は3局、スマートフォンは1局。選択した局数はブラウザーに保存し、既存の2局設定も維持します。共有URL・解析復元による一時的な局数は保存値を上書きしません。配置は自動・縦型・横型から選べ、端末に保存します。評価値・第一候補・読み筋は盤面の上、手順移動は下、棋譜は横または下に常設します。盤面・持駒の幅を揃え、1局表示は利用できる縦横に合わせて収めます。PCの操作幅は盤面へ揃え、狭いスマートフォンでは操作の押しやすさも確保します。

上部はPC・スマートフォンともに1行にまとめ、局数・解析時間・解析を共通操作にします。スマートフォンの配置、駒音・配色・統計等は設定メニュー内です。PCの3局はブラウザーの表示幅1440 CSS px以上で横並び、それ未満は折り返します。最後に操作して枠が強調された対局が全棋譜解析の対象です。盤面下は最初・前・次・最後・反転。本譜・変化の切替ボタンは置かず、棋譜内の枝から保存した変化を開き、分岐元へ戻れます。棋譜の手を押すと同じ盤面へ移動します。対局名は色付きの枠と▼で選択できることを示し、押すと大きな選択欄と再生操作が開きます。ピン留め・拡大・検討再開は「その他の操作」にまとめ、反転・共有・最初・最新の重複ボタンはメニューから省きます。上部の配置・局数は文字ラベルを省いて選択欄だけ表示します。各盤面下の右側に、その対局の同接人数・本日の来場者数を常時表示します。統計未取得は「—」とし、0人とは区別します。対局名の右側に「形式▼・コピー・DL・共有」を1行に並べ、過去局面の状態表示と「最新」ボタンは省きます。盤面下の「最後」で最新手への追従を再開します。形式はKIF/CSAから選び、コピー・DLで共通です。共有は元対局のURLをコピーし、変化の手順は含めません。

過去対局の「後手勝ちを探す」で勝敗が確認できた後手勝ちだけを絞り込み、AI名・レート条件と併用できます。「指定日を取得」後はその日の取得済み対局が対象です。取得範囲を画面に表示し、勝敗不明を勝ち側の検索に含めません。過去全件の自動巡回は行いません。レート条件は先手・後手の両者に適用し、両者とも指定した下限以上・上限以下の対局だけを表示します。条件指定時は片方でもレート不明なら除外し、未指定時はレート不明も含めます。検索条件（AI名・日付・グループ・結果・レート下限/上限・並び順・お気に入り）はこのブラウザーに自動保存し、再読み込み後も復元します。日付の対局取得は「指定日を取得」で行い、自動では取得しません。

## 全棋譜解析

1局面1・3・5・10秒、既定1秒。「解析」で開始し、「停止」「再開」に切り替わります。初期局面から開始時点の最終手までを固定し、一覧へ評価値と進捗・グラフを表示します。選択した手の解析結果を展開すると候補手と読み筋を参照できます。検討中は本譜と現在の変化を別々に解析・出力できます。KIFはUTF-8の.kifu、CSAは.csa。変化に別の枝や本譜の終局情報を混ぜません。

エンジンは1つです。全棋譜解析中は通常の局面解析を待機し、停止・終了後に再開します。別の対局を選ぶと前の全棋譜解析を停止し、完了した位置から手動再開できます。タブ非表示時も停止し、自動再試行しません。新着や変化がある場合は案内し、明示的に最新の棋譜へ戻せます。結果はメモリだけに保持し、対局切替・通常の再読み込みで消えます。初回解析準備の確認済みの1回の再読み込みだけ、明示した解析要求を復元します。

解析は端末のCPU・電池を使います。200手なら201局面で、探索だけの目安は1秒設定で約3分21秒、10秒で約33分30秒です。解析データの外部送信・有料API・サーバー解析はありません。詳細は[ワークスペース仕様](docs/WORKSPACE.md)を参照してください。

## 1局専用の検討モード

観戦中に手番側の駒または持ち駒を選び、強調された合法な移動先をタップ／クリックして着手を確定すると、1局専用の検討盤へ自動で切り替わります。成りの選択が必要な場合は、その確定後に開始します。駒の選択だけ・取消・不正な移動では切り替わりません。本譜の局面更新で選択を解除し、古い局面での着手を取り消します。最初の着手から変化として保存し、本譜には混ぜません。成り・不成、捕獲、持駒打ち、二歩、自玉の王手、打歩詰を検査します。ドラッグ、任意の駒配置編集やAI対局の機能はありません。

上部の状態表示は「検討中」に統一し、「変化○手」は表示しません。下部の手順移動用の手数表示は残します。

解析時間は1・3・5・10秒で既定1秒、最大3候補・各12手の読み筋を表示します。「停止」で現在の自動解析を止め、「再解析」で同じ局面も新しく探索します。観戦の解析は従来の500msのままです。数値や候補は参考値で、長時間ほど正解になる保証はありません。10秒の連続利用はCPU・電池を多く使います。

手戻し後に別の手を指すと枝として残り、元の枝も参照できます。「本譜」で元の対局・枠順・手数・反転・ピンを復元し、再生は停止して戻ります。選んだ局の追従は「最新」で明示的に再開します。検討中は対局の自動差し替え・他盤の棋譜再生・解析と観戦heartbeatを停止します。対象の本譜だけ新着を確認し、開始時点の本譜最終手からの増分を通知します。本譜には変化を混ぜません。

検討はsessionStorageに1件、最終更新から2時間、最大512KiB／1024ノード／1経路512手で保存します。通常の再読み込みでは自動開始せず対局名を押すと「前の検討を再開」を表示します。初回解析準備の確認済み再読み込みだけは自動復元します。別タブとの同期はありませんが、ブラウザーのタブ複製で初期コピーされる場合があります。保存拒否・容量超過時は変更を確定せず通知します。

同一局面4回・詰み・合法手なしで当該枝の入力と自動解析を止めます。反復は提供された棋譜初期局面以降だけを対象とし、連続王手の千日手など公式の勝敗を裁定しません。棋譜に不正な着手がある場合は、その着手より前の正常な局面から開始してください。

盤面の上に筋、右に段の座標を表示し、反転に連動します。持駒は駒と枚数だけを表示します。駒音はメニューと検討画面で切替でき、既定OFFです。音は端末内で合成し、外部音声素材の取得はありません。
