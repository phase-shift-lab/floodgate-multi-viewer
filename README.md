# Floodgate Multi Viewer

Floodgateの公開棋譜を1・2・4局で観戦するWebアプリです。フロントエンドはGitHub Pages、公開データのLIVE中継と匿名統計はCloudflare Workerで提供し、Worker未接続時は同梱fixtureへ安全にフォールバックします。

> 非公式ビューアです。Floodgateおよび運営組織による公式製品ではありません。

公開版: https://phase-shift-lab.github.io/floodgate-multi-viewer/

## 開発

Node.js 24系を推奨します。

```powershell
npm ci
npm run dev
```

検証:

```powershell
npm run lint
npm run typecheck
npm run test
npm run test:e2e
npm run build
```

## 構成

- `src/domain/`: CSA・HTML・レート解析、選定、再生ロジック
- `src/data/`: 同梱fixture、localStorage、LIVE中継クライアント
- `src/components/`: 盤面と対局パネル
- `worker/`: Floodgate公開データの許可リスト中継と匿名統計
- `e2e/`: デスクトップ、モバイル、再生、復元の検証

`VITE_API_BASE` にWorker URLを設定するとLIVE中継を利用します。未設定またはWorker障害時は「静的fixtureで表示中」へ切り替わります。ブラウザからFloodgate本体へは直接アクセスしません。

対局一覧より棋譜の終了情報が先に届いた場合も終了状態を反映します。終了時刻が明示された0手の棋譜は「不成立（0手終了）」と表示し、自動選出から除外します。確認済みの終了情報は端末に最大256件・24時間保持し、開き直した直後の選出にも反映します。配信元の手数が確認済みの値より増えた場合は、その終了情報を解除します。

起動時は着手のある対局を優先し、0手の自動選出候補は最大4局、各3秒で棋譜を確認してから採用します。確認済みの初手待ちはLIVEのままです。通信失敗・stale・fixtureの応答では終了情報を保存せず、未確認の0手対局は自動選出しません。保存が拒否されても起動時確認は継続し、候補がない場合は案内を表示します。共有URLで指定した対局はこの自動選出の除外対象にしません。

自動切替ONでは、終了確認時に次の30秒更新を待たず終了した枠だけを差し替えます。共有URLの指定・ピン留め・過去手の閲覧・詳細表示中の枠、自動切替OFFは維持します。通信失敗時は直前の盤面を保持し、60秒、以後最大120秒の間隔で再取得します。復帰後は通常の30秒間隔に戻り、非表示タブでは120秒間隔に抑えます。

## 端末での局面解析

つようら王11microと対応やねうら王WASMで現在の局面を端末上で解析します。初期ONで、盤面の上に先手基準の評価値・形勢ゲージ・第一候補・探索深さを表示します。ゲージは勝率ではありません。「候補手・読み筋」を開くと最大3候補と各6手までの日本語読み筋、解析ON/OFFを確認できます。対局ごとのOFF設定は保存し、OFF時はエンジンを読み込みません。CSAに含まれる評価値とは区別します。

エンジンは全盤で1つ、探索スレッド1、ハッシュ16MB、1局面500msです。複数盤は順番に解析し、局面変更時は古い探索を中止します。非表示時は探索を停止し、解析結果を最大128局面までメモリ内に保持します。観戦中に履歴全体を自動解析することはありません。端末のCPU・電池を使用し、実行メモリは評価ファイルの約4.9MBより大きくなります（WASM初期メモリ132MiB）。

共有メモリを利用するため、初回解析時にアプリのパス内限定のService Workerを登録し、1回再読み込みします。表示対局・手数・反転・解析ON状態をsessionStorageで一時復元します。Workerはキャッシュせず、同一アプリの応答にCOOP/COEPを付与します。外部通信にはヘッダーを追加しません。「候補手・読み筋」内の解除ボタンで登録を解除して再読み込みできます。解除後は自動解析を停止し、手動でONにすると再開します。再読込後も共有メモリを利用できない場合はエラー表示で停止し、再読込を繰り返しません。

解析局面・結果の送信、有料API、サーバー側の解析はありません。配布ライセンス・対応ソース・ビルド手順は `public/engine/NOTICE.txt` と `public/engine/source.zip` を参照してください。評価関数はMIT、探索エンジンはGPLv3です。

解析準備は局面更新と独立して継続し、初回の再読み込み直前に表示していた対局・手数、検討の手順を保存します。手動OFF・画面離脱では準備を中断します。中断と起動失敗を区別して表示し、失敗時は評価欄の「解析を再試行」から手動で再開できます。初回ON・手動OFFの保存と再読み込みループ防止は維持します。

## 共通の観戦・棋譜・検討画面

観戦・棋譜解析・検討の3モードボタンを撤去し、同じ盤面と下部操作を使います。右端の「棋譜」で中央ポップアップの棋譜を開き、任意の手を選ぶとプレビューへ反映し、「盤面に表示」で元の盤へ移動して閉じます。手動移動ではライブ追従を停止し、「最新」で再開します。棋譜を開くだけでは1局表示に切り替えません。

ポップアップはPC・スマホ共通で幅80％、棋譜は最大1000px、読み筋・設定は最大640pxです。高さは最大80％で、短い棋譜は内容に合わせて縮みます。本譜／変化ボタンはPCで各100pxを目安にし、狭い画面では収まる幅に調整します。タブ行を省き、棋譜・読み筋・設定はそれぞれ独立した内容で開きます。読み筋は上部評価欄、設定は歯車から開きます。固定見出しと一つの本文スクロール領域を備え、文字拡大時は操作を折り返して収めます。現在手へ一度だけ自動スクロールし、新着で位置を奪いません。閉じるボタン・背景タップ・Escで閉じます。開閉しても盤面サイズは変えません。

評価値・形勢・第一候補は盤の上、手順操作とスライダーは盤の下。対局者は盤の上下に「▲先手／△後手・名前・手番・レート・☆」を表示し、反転に連動して持駒とともに入れ替わります。評価値は反転にかかわらず先手基準で、「読み筋」は評価欄の右上に配置します。下部は「反転・再生・←・→・棋譜」の横一列とスライダー・右下の手数表示です。検討中は「再生」が「起点へ」に切り替わり、対局名の位置に「検討中」、その行の右端に「本譜」を表示します。共有もこの見出し行に配置します。対局名から対局選択・ピン留め・拡大・検討再開、評価欄から読み筋、上部の歯車から最後に触れた盤の解析・再生設定を開きます。主要なスマホ操作は高さ44px以上で、低い画面と文字拡大時は縦スクロールを許可します。持駒の有無・枚数で高さは変わりません。

## 全棋譜解析

棋譜ポップアップの見出し行に「KIF／CSA・棋譜コピー・棋譜DL」の順で並び、形式はコピー・DL共通です。出力形式はKIF（既定）／CSA。KIFはUTF-8の`.kifu`、CSAは`.csa`で保存します。観戦中は閲覧中の手数にかかわらず取得済みの本譜全体を出力します。検討中は「本譜／変化」を選べ、変化は本譜の起点までと現在選択している局面までの手順だけを含み、本譜の終局情報や別の枝は含みません。出力は端末内で行います。

下部の「棋譜」から中央ポップアップを開き、棋譜と全棋譜解析を同じ画面で扱います。解析前からPCは左に幅320〜360pxの棋譜一覧、右に選択局面のプレビューを表示します。スマホは棋譜一覧／選択局面・読み筋を切り替えます。手を選ぶとプレビューへ反映し、「盤面に表示」で元の盤へ移動して閉じます。見出しの次の1行に、本譜／変化の切替（変化は検討中に選択可能）・1局面1・3・5・10秒（既定1秒）・解析操作を並べます。時間を選び「解析」を押すと、一覧の各手に評価値を併記し、グラフと選択局面の候補手・読み筋を表示します。解析操作は同じボタンが「解析／停止／再開」に切り替わり、最初からの解析は「解析の詳細」にあります。コピー・DLの結果は一時表示し、行を増やしません。解析後は同じ一覧とプレビューに評価値・候補手・読み筋を加えます。初期局面を含め、開始時点の本譜の最終手までを固定して1局面ずつ解析します。検討中は「本譜／変化」で表示・解析・出力を揃えます。現在の変化は、本譜の起点までと現在選択している局面までの1経路を対象にします。「他の変化を選ぶ」から別の枝も参照できます。別の枝は混ぜません。LIVEの追加手は自動で対象へ追加せず、「最初から解析」で取り込み直します。新着や変化の変更があると案内し、「最新の棋譜を表示」で解析を止めて結果を破棄し、解析なしの最新一覧へ戻せます。解析後のコピー・DLも表示中の固定した手順を出力します。

エンジン・探索スレッドは従来どおり1つです。全棋譜解析中は通常の局面解析を待機させ、終了・停止後に再開します。進捗、先手基準の評価値グラフ、各手の数値、最大3候補・各12手の読み筋を表示します。手を選ぶと解析した固定棋譜の盤面を表示するため、LIVE更新や別の枝と結果を取り違えません。グラフは表示を±3000で制限し、詰みは端に表示します。勝率ではありません。スマホは棋譜一覧と選択局面・読み筋を切り替えて表示します。

途中停止と続きからの再開ができます。ポップアップを閉じる・別の対象へ切り替えると停止し、画面が非表示になった場合も一時停止して手動再開を待ちます。エラーは自動再試行しません。時間を変えた場合は最初から解析します。不正な棋譜はエンジン投入前の検証で停止します。結果は対象パネルのメモリだけに保持し、対局の切替・検討盤の終了・再読み込みで消えます。初回の解析準備で行う確認済みの1回の再読み込みだけは、明示した開始要求と対象棋譜を一時保存して復元します。通常の再読み込みでは解析を勝手に開始しません。

端末のCPU・電池を使用します。200手なら初期局面を含め201局面で、1秒設定でも探索だけで約3分21秒、10秒設定なら約33分30秒が目安です。準備・検証時間は別にかかります。解析データの外部送信・有料API・サーバー解析はありません。
## 1局専用の検討モード

観戦中に手番側の駒または持ち駒を選び、強調された合法な移動先をタップ／クリックして着手を確定すると、1局専用の検討盤へ自動で切り替わります。成りの選択が必要な場合は、その確定後に開始します。駒の選択だけ・取消・不正な移動では切り替わりません。本譜の局面更新で選択を解除し、古い局面での着手を取り消します。最初の着手から変化として保存し、本譜には混ぜません。成り・不成、捕獲、持駒打ち、二歩、自玉の王手、打歩詰を検査します。ドラッグ、任意の駒配置編集やAI対局の機能はありません。

上部の状態表示は「検討中」に統一し、「変化○手」は表示しません。下部の手順移動用の手数表示は残します。

解析時間は1・3・5・10秒で既定1秒、最大3候補・各12手の読み筋を表示します。「停止」で現在の自動解析を止め、「再解析」で同じ局面も新しく探索します。観戦の解析は従来の500msのままです。数値や候補は参考値で、長時間ほど正解になる保証はありません。10秒の連続利用はCPU・電池を多く使います。

手戻し後に別の手を指すと枝として残り、元の枝も参照できます。「本譜」で元の対局・枠順・手数・反転・ピンを復元し、再生は停止して戻ります。選んだ局の追従は「最新」で明示的に再開します。検討中は対局の自動差し替え・他盤の棋譜再生・解析と観戦heartbeatを停止します。対象の本譜だけ新着を確認し、開始時点の本譜最終手からの増分を通知します。本譜には変化を混ぜません。

検討はsessionStorageに1件、最終更新から2時間、最大512KiB／1024ノード／1経路512手で保存します。通常の再読み込みでは自動開始せず対局名を押すと「前の検討を再開」を表示します。初回解析準備の確認済み再読み込みだけは自動復元します。別タブとの同期はありませんが、ブラウザーのタブ複製で初期コピーされる場合があります。保存拒否・容量超過時は変更を確定せず通知します。

同一局面4回・詰み・合法手なしで当該枝の入力と自動解析を止めます。反復は提供された棋譜初期局面以降だけを対象とし、連続王手の千日手など公式の勝敗を裁定しません。棋譜に不正な着手がある場合は、その着手より前の正常な局面から開始してください。

盤面の上に筋、右に段の座標を表示し、反転に連動します。持駒は駒と枚数だけを表示します。駒音はメニューと検討画面で切替でき、既定OFFです。音は端末内で合成し、外部音声素材の取得はありません。
