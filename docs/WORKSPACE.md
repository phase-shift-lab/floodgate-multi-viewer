# 共通の観戦・検討・棋譜ワークスペース

未保存時はPC3局、スマートフォン1局。ユーザーの局数選択はブラウザーに保存し、既存の有効な2局設定も維持する。共有URL・解析復元の一時的な局数は保存設定を上書きせず、手動の局数変更だけを保存する。配置は自動・縦型・横型で端末に保存する。局数は1/2/3/4局。自動配置はPC1/2/3局で盤面横に棋譜、4局や狭い画面で盤面下へ置く。3局はブラウザーの表示幅1440 CSS px以上で3列、それ未満は2列、1100px未満では1列に折り返し、追加行は一覧内でスクロールする。1920pxの3局は棋譜幅160〜180px、1/2局は200〜240pxを確保する。横型の指定もスマートフォンでは縦型へ戻し、横はみ出しを避ける。

上部は1行に統合し、PCはタイトル・画面切替・配置・局数・解析時間・解析操作・設定を置く。スマートフォンはロゴ・局数・解析時間・解析操作・設定を置き、配置・画面切替・駒音・配色・統計等は設定内へまとめる。選択中の盤の設定は同じメニューから開く。全棋譜解析の対象は枠で強調された最後に操作した対局。対象を切り替えると前の探索を停止し、完了位置を維持して手動再開できる。1/3/5/10秒、既定1秒。通常の観戦局面解析は500ms、検討の局面解析時間は検討設定に従う。

評価値・形勢ゲージ・第一候補を先頭に強調した読み筋を、盤面上の一つの解析欄へ置く。評価欄はPC64px、スマートフォン48px。読み筋を押すとモーダルで他候補・全文・解析ON/OFF・エンジン名を表示し、盤面を押し下げない。値は先手基準、ゲージは勝率ではない。エンジン、ライセンス、初回共有メモリ準備、手動OFF保存、再読み込みループ防止は維持する。

盤面下は最初/前/次/最後/反転と現在手数。本譜/変化の切替ボタンは置かない。棋譜の分岐位置に保存した枝を表示し、手を押すと検討を復元・検証して同じ盤面へ反映する。検討中は棋譜の分岐元から観戦へ戻り、兄弟の枝を同じ一覧から選べる。通常の再読み込み後は棋譜内の「保存した変化を開く」から明示再開する。全棋譜解析・出力の元対局/現在の変化の選択は、検討中の棋譜一覧末尾に直接置く。対局名は高さ44px以上の色付き枠と▼で選択できることを示し、スマートフォンでは名前を2行まで表示する。メニューの選択欄は高さ48px・文字16pxとする。再生だけを直下に置き、ピン留め・拡大・検討再開は「その他の操作」にまとめる。反転・共有・最初・最新はメニューから省き、常設操作を使う。過去局面の状態表示と「最新」ボタンを省き、「最後」の操作で最新手への追従を再開する。棋譜は常設し、任意の手を押すと同じ盤面へ移動する。対局名の右側へ形式（KIF/CSA）・コピー・DL・共有をこの順で1行に並べる。棋譜上部の重複した出力操作は置かない。コピーとDLは同じ形式選択を使い、全棋譜解析中は凍結した棋譜を出力する。共有は元対局のURLだけを扱い、変化の棋譜を含めない。「棋譜の操作」の折りたたみ見出しと重複する解析説明は置かない。解析開始後の再解析は棋譜一覧末尾に、検討時の手順選択・変化履歴も必要なときだけ直接表示する。

駒の合法な着手確定で検討へ入り、変化を本譜へ混ぜない。枝保存、二歩/打歩詰/自玉王手の検査、成り、保存失敗時の停止、新着通知、元の枠順/手数/反転/ピン復元は既存の処理を使う。

## 画面の収まり

局数の変更では選択中の対局を先頭に残し、次にピン留め・既存表示を優先し、増やした枠だけ注目対局を補充する。対局表示の識別子は枠番号から独立させ、選択対局が先頭へ移っても手数・反転・棋譜一覧のスクロール・解析結果を再初期化しない。同じ対局を複数枠へ表示している場合も、それぞれの状態を区別する。

統合画面の棋譜の選択手数は盤面側で管理し、全棋譜解析の開始・進捗・詰み結果で独自に0手目へ戻さない。解析用に固定した棋譜を表示する場合は、その最終手までに制限する。別画面の解析結果プレビューでは従来の独立した手順選択を維持する。

棋譜一覧のスクロール位置は解析結果の更新・詰み評価・一時非表示からの再表示でも保持する。初回表示のみ選択手へ位置を合わせ、ユーザーがスクロールした後は自動で中央へ戻さない。棋譜領域のブラウザー標準スクロールアンカーも無効にする。

上下の持駒欄は空でも同じ高さを確保し、駒の取得・消費・反転で盤面の大きさや位置を変えない。同じ配置の複数局も持駒の有無で大小が変わらないようにする。高さ600px以下のスマートフォンでは持駒と枚数を横並びの1段に収め、盤面と棋譜の表示領域を維持する。

1局表示は見出し・解析欄・棋譜・操作の高さを確保し、実際に残った縦横へ盤面を正方形で合わせる。持駒・枚数・対局者は盤面と同じ幅のまとまりにし、PCでは操作の左右端も盤面へ揃える。スマートフォンの出力操作も高さ44pxとし、棋譜の内部スクロールに最低56pxを確保する。スマートフォンの盤面操作は高さ44px、合計幅232px以上を基本とし、盤面がそれより小さい場合は列内へ中央配置する。棋譜の見出しに現在手数を残し、スマートフォンでは下部の重複表示を視覚的に省く。候補や棋譜は各領域の中でスクロールし、盤面を押し出さない。複数局の追加行は盤面一覧領域の中でスクロールする。

設定ダイアログは既存のフォーカス・Esc・背景操作を維持する。棋譜と読み筋のために別の盤面プレビューを作らない。駒音は既定OFF。夜明けのロゴを表示する。

## 検証と公開範囲

lint、typecheck、ユニットテスト、build、E2Eで実エンジン・準備再読み込み・解析停止/再開・棋譜出力・検討保存・LIVE追従・配置保存を確認する。PC1/2/3/4局とスマートフォンの低い/通常画面を描画し、上下端・左右端と棋譜内部スクロールを測る。iPhone/Safari実機は別の確認とする。

公開対象はアプリコード・テスト・この仕様とREADME・ロゴ。ローカルプレビューツール、共通指示、作業ログ、バックアップ、個人情報は公開しない。Workerとエンジン配布物・外部API・依存の追加は行わない。

## 過去対局の勝ち側検索

「後手勝ちを探す」は既存の結果フィルターを後手勝ちに変更する。終局かつ結果が後手勝ちと確認された対局だけを含め、勝敗不明を除外する。AI名・グループ・レート・お気に入りと併用する。指定日を取得した後は開始日の一致する取得済み対局だけを表示し、検索範囲を明記する。同梱データへのフォールバックは指定日の実データとして表示しない。過去全件の巡回や新しい外部経路は追加しない。

レート条件は先手・後手の両者に適用し、両者とも指定した下限以上・上限以下の対局だけを表示します。条件指定時は片方でもレート不明なら除外し、未指定時はレート不明も含めます。

過去対局の一覧・最近見た対局から選択した棋譜は、先頭の表示枠を選択し、単局拡大を解除して表示する。手動選択した終局済み対局は、終局確認や一覧更新で注目局へ自動差し替えしない。対局名メニューから選択した過去対局も同様とし、通常のライブ対局の終局後切替は維持する。

過去対局の検索条件（AI名・日付・グループ・勝敗・レート下限/上限・並び順・お気に入りのみ）は専用のブラウザー保存領域に自動保存・復元する。日付の復元だけでは指定日を取得せず、取得範囲の表示を維持する。一覧未取得の保存済みグループも選択欄へ残す。壊れた保存値は項目単位で既定へ戻し、保存に失敗した場合はタブ内だけに保持する旨を表示する。共有URLや他端末への同期は行わない。

上部の配置・局数は視覚的な文字ラベルを省き、選択欄の読み上げ名を維持する。各盤面下の接続情報の右側へ、その対局の同接人数・本日の来場者数を常時表示する。未取得は「—」とし、0人と区別する。狭い画面と4局表示では取得時刻を省く。既存の統計取得経路と頻度を維持し、複数盤の人数を合計してサイト全体の同接と扱わない。
