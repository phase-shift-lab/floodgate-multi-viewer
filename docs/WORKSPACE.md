# 共通の観戦・検討・棋譜ワークスペース

未保存時はPC3局、スマートフォン1局。ユーザーの局数選択はブラウザーに保存し、既存の有効な2局設定も維持する。共有URL・解析復元の一時的な局数は保存設定を上書きせず、手動の局数変更だけを保存する。配置は自動・縦型・横型で端末に保存する。局数は1/2/3/4局。自動配置はPC1/2/3局で盤面横に棋譜、4局や狭い画面で盤面下へ置く。3局はブラウザーの表示幅1440 CSS px以上で3列、それ未満は2列、1100px未満では1列に折り返し、追加行は一覧内でスクロールする。1920pxの3局は棋譜幅160〜180px、1/2局は200〜240pxを確保する。横型の指定もスマートフォンでは縦型へ戻し、横はみ出しを避ける。

上部は1行に統合し、PCはタイトル・画面切替・配置・局数・解析時間・解析操作・設定を置く。スマートフォンはロゴ・局数・解析時間・解析操作・設定を置き、配置・画面切替・駒音・配色・統計等は設定内へまとめる。選択中の盤の設定は同じメニューから開く。全棋譜解析の対象は枠で強調された最後に操作した対局。対象を切り替えると前の探索を停止し、完了位置を維持して手動再開できる。1/3/5/10秒、既定1秒。通常の観戦局面解析は500ms、検討の局面解析時間は検討設定に従う。

評価値・形勢ゲージ・第一候補を先頭に強調した読み筋を、盤面上の一つの解析欄へ置く。評価欄はPC64px、スマートフォン48px。読み筋を押すとモーダルで他候補・全文・解析ON/OFF・エンジン名を表示し、盤面を押し下げない。値は先手基準、ゲージは勝率ではない。エンジン、ライセンス、初回共有メモリ準備、手動OFF保存、再読み込みループ防止は維持する。

盤面下は最初/前/次/最後/反転と現在手数。本譜/変化の切替ボタンは置かない。棋譜の分岐位置に保存した枝を表示し、手を押すと検討を復元・検証して同じ盤面へ反映する。検討中は棋譜の分岐元から観戦へ戻り、兄弟の枝を同じ一覧から選べる。通常の再読み込み後は棋譜内の「保存した変化を開く」から明示再開する。全棋譜解析・出力の元対局/現在の変化の選択は棋譜の操作内の選択欄に残す。対局名には対局選択の案内を置き、メニューの選択欄は高さ48px・文字16pxとする。再生だけを直下に置き、ピン留め・拡大・検討再開は「その他の操作」にまとめる。反転・共有・最初・最新はメニューから省き、常設操作を使う。棋譜は常設し、任意の手を押すと同じ盤面へ移動する。棋譜一覧内の「棋譜の操作」で形式・コピー・DL・再解析を利用する。コピーとDLは同じ形式選択を使い、全棋譜解析中は凍結した棋譜を出力する。

駒の合法な着手確定で検討へ入り、変化を本譜へ混ぜない。枝保存、二歩/打歩詰/自玉王手の検査、成り、保存失敗時の停止、新着通知、元の枠順/手数/反転/ピン復元は既存の処理を使う。

## 画面の収まり

1局表示は見出し・解析欄・棋譜・操作の高さを確保し、実際に残った縦横へ盤面を正方形で合わせる。持駒・枚数・対局者は盤面と同じ幅のまとまりにし、PCでは操作の左右端も盤面へ揃える。スマートフォンの操作は高さ44px、合計幅232px以上を基本とし、盤面がそれより小さい場合は列内へ中央配置する。棋譜の見出しに現在手数を残し、スマートフォンでは下部の重複表示を視覚的に省く。候補や棋譜は各領域の中でスクロールし、盤面を押し出さない。複数局の追加行は盤面一覧領域の中でスクロールする。

設定ダイアログは既存のフォーカス・Esc・背景操作を維持する。棋譜と読み筋のために別の盤面プレビューを作らない。駒音は既定OFF。夜明けのロゴを表示する。

## 検証と公開範囲

lint、typecheck、ユニットテスト、build、E2Eで実エンジン・準備再読み込み・解析停止/再開・棋譜出力・検討保存・LIVE追従・配置保存を確認する。PC1/2/3/4局とスマートフォンの低い/通常画面を描画し、上下端・左右端と棋譜内部スクロールを測る。iPhone/Safari実機は別の確認とする。

公開対象はアプリコード・テスト・この仕様とREADME・ロゴ。ローカルプレビューツール、共通指示、作業ログ、バックアップ、個人情報は公開しない。Workerとエンジン配布物・外部API・依存の追加は行わない。

## 過去対局の勝ち側検索

「後手勝ちを探す」は既存の結果フィルターを後手勝ちに変更する。終局かつ結果が後手勝ちと確認された対局だけを含め、勝敗不明を除外する。AI名・グループ・レート・お気に入りと併用する。指定日を取得した後は開始日の一致する取得済み対局だけを表示し、検索範囲を明記する。同梱データへのフォールバックは指定日の実データとして表示しない。過去全件の巡回や新しい外部経路は追加しない。
