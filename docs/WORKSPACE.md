# 共通の観戦・検討・棋譜ワークスペース

PCは初期2局、スマートフォンは1局。共有URLの明示指定と既存の局数設定は保持する。配置は自動・縦型・横型で端末に保存する。自動配置はPC1/2局で盤面横に棋譜、4局や狭い画面で盤面下へ置く。横型の指定もスマートフォンでは縦型へ戻し、横はみ出しを避ける。

共通操作行は配置・局数・解析時間・解析操作。全棋譜解析の対象は枠で強調された最後に操作した対局。対象を切り替えると前の探索を停止し、完了位置を維持して手動再開できる。1/3/5/10秒、既定1秒。通常の観戦局面解析は500ms、検討の局面解析時間は検討設定に従う。

評価値・形勢ゲージ・第一候補を先頭に強調した読み筋を、盤面上の一つの解析欄へ置く。他候補と解析設定は展開式。値は先手基準、ゲージは勝率ではない。エンジン、ライセンス、初回共有メモリ準備、手動OFF保存、再読み込みループ防止は維持する。

盤面下は本譜/変化・最初/前/次/最後と現在手数。反転・再生・共有・対局選択・ピン留め・拡大は対局名の操作メニューから利用する。検討中は上部に本譜復帰・反転・共有も表示する。棋譜は常設し、任意の手を押すと同じ盤面へ移動する。棋譜一覧内の「棋譜の操作」で形式・コピー・DL・再解析を利用する。コピーとDLは同じ形式選択を使い、全棋譜解析中は凍結した棋譜を出力する。

駒の合法な着手確定で検討へ入り、変化を本譜へ混ぜない。枝保存、二歩/打歩詰/自玉王手の検査、成り、保存失敗時の停止、新着通知、元の枠順/手数/反転/ピン復元は既存の処理を使う。

## 画面の収まり

1局表示は見出し・解析欄・棋譜・操作の高さを確保し、実際に残った縦横へ盤面を正方形で合わせる。持駒・枚数・対局者は盤面と同じ幅のまとまりにし、操作の左右端も盤面へ揃える。盤面が小さい画面では操作も適切に縮むが、高さ44pxを維持する。候補や棋譜は各領域の中でスクロールし、盤面を押し出さない。複数局の追加行は盤面一覧領域の中でスクロールする。

設定ダイアログは既存のフォーカス・Esc・背景操作を維持する。棋譜と読み筋のために別の盤面プレビューを作らない。駒音は既定OFF。夜明けのロゴを表示する。

lint、typecheck、ユニットテスト、build、E2Eで実エンジン・準備再読み込み・解析停止/再開・棋譜出力・検討保存・LIVE追従・配置保存を確認する。PC1/2/4局とスマートフォンの低い/通常画面を描画し、上下端・左右端と棋譜内部スクロールを測る。iPhone/Safari実機は別の確認とする。

公開対象はアプリコード・テスト・この仕様とREADME・ロゴ。ローカルプレビューツール、共通指示、作業ログ、バックアップ、個人情報は公開しない。Workerとエンジン配布物・外部API・依存の追加は行わない。
